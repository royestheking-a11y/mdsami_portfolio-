# MD SAMI | Digital Identity & Systems Portfolio

A premium, high-performance personal portfolio and digital identity system engineered for MD Sami. Built using modern web technologies to showcase technical projects, research experiences, and a complete skill stack with dynamic, interactive elements.

## ✨ Features
- **Cinematic Hero Section:** Immersive UI with premium blurred backdrops, glassmorphic elements, and dynamic animations.
- **Interactive Tech Stack Sphere:** A fully animated CSS/SVG-driven spherical display showcasing core technologies.
- **Active Contact Console:** Real-time form submissions powered by asynchronous endpoints (FormSubmit API) with processing feedback.
- **Custom Inspector Console:** An interactive "hacker-like" sandbox terminal allowing users to run diagnostics and system checks natively in the browser.
- **Cross-Platform Responsive Design:** Built pixel-perfect for mobile, tablet, and ultra-wide displays.
- **Vite 6 Engine Optimization:** State-of-the-art build tooling guaranteeing blazing-fast delivery and performance.

## 🛠 Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Email Delivery:** FormSubmit API
- **Platform Ready:** Pre-configured for Vercel

## 🚀 Running the Code Locally
To run this project on your local machine:
1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
